# Store Management

Monorepo untuk aplikasi Store / Shop Management System yang dibangun dengan arsitektur backend API dan frontend SPA.

Repository ini dibuat sebagai bagian dari technical assessment, dengan fokus pada struktur proyek yang rapi, workflow Git profesional, serta penerapan CI dan code quality tooling.

---

## Tech Stack

Backend

- Laravel 11
- RESTful API
- JWT Authentication
- PHPUnit
- Laravel Pint (code style)

Frontend

- Vue 3
- Vite
- Single Page Application (SPA)
